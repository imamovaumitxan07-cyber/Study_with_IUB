STUDY WITH IUB — ILOVA (PWA) v3.0.0
====================================

Bul papka — tayar ilova. Ol telefonǵa (Android, iPhone) hám kompyuterge
ilova retinde ornatıladı, internetsiz de isleydi.

1) ILOVANI INTERNETKE SHÍǴARÍW (biypul, 2 minut)
   A. Netlify Drop (eń ańsat):
      - https://app.netlify.com/drop saytın ashıń
      - usı papkanı (index.html bar papkanı) betke súyrep taslań
      - siltemeni alasız, mısalı: https://study-with-iub.netlify.app
   B. GitHub Pages: jańa repozitoriyaǵa usı fayllardı júklep,
      Settings → Pages → "Deploy from branch" ni qosıń.

   ESKERTIW: index.html ni kompyuterde tikkeley eki ret basıp ashsańız
   (file://...), PDF oqıw hám oflayn rejim islemeydi. Ilova https
   mánzilinde isleydi.

2) TELEFONǴA ORNATÍW
   - Android (Chrome): siltemeni ashıń → menyu (⋮) → "Ilovanı ornatıw"
   - iPhone (Safari): siltemeni ashıń → "Bólisiw" → "Bas ekranǵa qosıw"
   - Kompyuter (Chrome/Edge): mánzil qatarındaǵı ornatıw belgisi

3) GOOGLE PLAY USHÍN APK (ixtiyarıy)
   Siltemeni https://www.pwabuilder.com saytına kiritip, Android paketin
   (APK/AAB) jaratıwǵa boladı. Google Play-ǵa shıǵarıw ushın
   Google Play Developer akkauntı kerek (bir mártelik tólem bar).

MAǴLÍWMATLAR
   - Barlıq maǵlıwmatlar paydalanıwshınıń óz qurılmasında saqlanadı
     (IndexedDB + localStorage). Server joq.
   - Rezerv: Sazlawlar → "Barlıǵın eksport (JSON)". Basqa qurılmaǵa
     ótkende: "Rezervten tiklew".
   - Claude-daǵı versiyadan maǵlıwmattı kóshiriw: sol jerde eksport →
     bul ilovada "Rezervten tiklew".

BUL VERSIYADA JOQ
   - AI funkciyaları (server hám AI API giltisi kerek).
   - Jámiyet (ortaq server kerek).
